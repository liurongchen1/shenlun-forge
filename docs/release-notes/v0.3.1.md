## 这个版本改了什么 / What changed

没有行为变化，只改了两件事。

**1. 包的简介换成了站得住的说法。** 原来写的是"分析式压缩策略"，但六轮实测没能证实它：
在普通工作对话上，压缩与直接截断打平，唯一的大效应来自**检索器**而不是压缩流水线。
现在的说法是「能让你在自己的对话上测出有没有用」——这是实测活下来的那个能力。

**2. 加了一句求星。** README、包文档字符串、命令行各一处。命令行只在每台机器上提示一次
（写本地标记）——每次运行都提醒的库，比从不提醒的更糟。

**The package summary now claims only what can be checked**, and a one-time star
request was added. No behaviour change.
