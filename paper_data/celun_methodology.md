# 策论解题方法论 —— ShenlunForge 策论引擎参考

## 来源
环球网校、中公教育、华图教育、上岸研究室-半月谈对策写法、考编日常备考社等

## 一、核心理念

策论的本质：**面对复杂问题，系统性地分析形势、权衡利弊、提出可执行的分层策略。**

与申论的区别：
- 申论：侧重信息提取与归纳概括（"材料说了什么"）
- 策论：侧重问题解决与策略生成（"应该怎么做"）

## 二、审题五要素

| 要素 | 含义 | ShenlunForge映射 |
|---|---|---|
| 问几问 | 要几个答案？先问题后对策？还是纯对策？ | Query复杂度评估，决定输出结构 |
| 作答范围 | 看哪些材料？ | 消息范围筛选（哪些messages相关） |
| 身份限制 | 不同角色提不同对策 | 输出视角/角色约束 |
| 字数要求 | 决定详略 | Token budget分配 |
| 特殊要求 | 针对性/可行性/操作性/系统性 | 输出质量标准 |

## 三、对策来源三渠道（核心创新点）

### 渠道1：直接对策（材料显式给出）
- 标志词：要、应该、必须、亟需、亟待、将、加快
- 来源：专家建议、政策文件、领导指示、成功经验
- **ShenlunForge映射**：Retriever直接提取显式信息（已有能力）

### 渠道2：间接对策/反推（最核心，需要LLM推理）
| 路径 | 材料内容 | 反推方法 | ShenlunForge映射 |
|---|---|---|---|
| 问题→对策 | 问题描述 | 问题反过来写 | Strategist: Problem→Solution推理 |
| 原因→对策 | 原因分析 | 针对原因提方案 | Strategist: Causal→Solution推理 |
| 经验→对策 | 成功案例 | 直接借鉴 | Strategist: BestPractice迁移 |
| 教训→对策 | 失败案例 | 反向推导 | Strategist: AntiPattern规避 |

### 渠道3：常用对策补充（六大维度万能库）
| 维度 | 常用对策 | ShenlunForge映射 |
|---|---|---|
| 思想观念 | 宣传教育、提高认识、树立典型 | 认知层面策略 |
| 制度规则 | 完善法规、健全机制、明确责任 | 制度层面策略 |
| 资源保障 | 财政投入、社会资本、人才培养 | 资源层面策略 |
| 监管执法 | 日常监管、专项整治、加大处罚 | 监管层面策略 |
| 技术支撑 | 大数据/AI、信息平台、数据打通 | 技术层面策略 |
| 社会协同 | 第三方评估、群众举报、政企合作 | 协同层面策略 |

**缺什么补什么：**
- 缺思想→宣传教育+手段内容创新
- 缺资金→财政补贴+社会资本+多元融资
- 缺人才→培养本地+引进外部+打通晋升
- 缺监管→专项整治+联合执法+群众监督
- 缺制度→完善法规+细化条例+建立标准

## 四、对策加工——从粗到精

### 标准句式
**主体 + 动作 + 对象 + 结果**

| 低分写法 | 高分写法 |
|---|---|
| 加强对基层医疗的重视 | 县政府应设立乡村医疗专项补贴，对驻村医生给予岗位津贴，稳定基层队伍 |
| 加强监管 | 市场监管部门应建立电商平台日常巡查机制，对违规商家实施信用扣分与限期整改 |

### 五大分类维度
1. 思想观念类（宣传、教育、引导、培训）
2. 制度规则类（完善制度、细化条例、建立机制）
3. 监管执法类（加强监管、严格执法、专项整治）
4. 资源保障类（资金、人才、技术、场地）
5. 社会协同类（联动多方、政企合作、群众参与）

### 对策升维
- 思维升维：头痛医头→系统治理
- 主体多元：政府包办→多元共治
- 工具数智：传统手段→数字化手段
- 动词升级：加强→筑牢/夯实/锚定；解决→纾解/破题

## 五、四性自查清单（输出质量验证）

| 性质 | 检查问题 | ShenlunForge映射 |
|---|---|---|
| 针对性 | 对策是否针对具体问题？ | 输出是否精准回应query？ |
| 可行性 | 现有条件下能否做到？ | 建议是否基于上下文中的实际约束？ |
| 操作性 | 谁来做？怎么做？什么效果？ | 建议是否具体可执行？ |
| 系统性 | 多维度覆盖还是单一维度？ | 是否考虑了多个维度/角度？ |

## 六、五大避坑指南

1. 对策与问题脱节——必须一一对应
2. 主体责任模糊——必须明确"谁来做"
3. 空话套话——必须写具体怎么做
4. 不考虑成本——必须说明资源来源
5. 脱离材料编造——所有建议必须有上下文依据
